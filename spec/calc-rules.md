# 계산 규칙 (lib/quote.ts)

## ㎡당 장수
- 타일: `1,000,000 / (가로mm × 세로mm)`
- 벽돌: `올림(1,000,000 / ((길이mm + 12) × (높이mm + 12)))` — 줄눈 12mm, 폭(가운데 값)은 쓰지 않음, 소수점 없음
  - 예: 190x90x57 → 1,000,000 / (202 × 69) = 71.75 → 72장
- `piecesPerSqm`에 직접 값이 있으면 그 값을 우선

## 견적 (장수 계산 전용 — 단가는 자주 바뀌므로 금액은 다루지 않음)
- 로스율 기본값: 타일 10%, 벽돌 5% (화면에서 바꿀 수 있음)
- 필요 장수 = 올림(면적 × ㎡당 장수 × (1 + 로스율))
- 타일(박스): 포장 수 = 올림(필요 장수 / piecesPerPack), 주문 장수 = 포장 수 × piecesPerPack
- 벽돌(파렛트): 올림하지 않음 → `내림(필요 장수 / piecesPerPack)파렛트 + 나머지 장` (예: 1파렛트 + 968장), 주문 장수 = 필요 장수
- 장수는 천 단위 쉼표

## 재고 신호등
- 빨강: stock < reorderPoint
- 노랑: stock < reorderPoint × 1.5
- 초록: 그 외

## 샘플
- 단계 순서: 포장 → 발송 → 도착 → 피드백 (피드백에서 더 안 감)
- 발송 단계에서 sentDate로부터 7일 초과면 노란 테두리

## 테스트 (손으로 검산 가능하게 3개 이상)
- 타일 600x600, 20㎡, 로스 10%: ㎡당 2.777… → 필요 62장 → (박스 4장이면) 16박스 → 64장
- 벽돌 ㎡당 75장, 30㎡, 로스 5%: 필요 2,363장 → (파렛트 500장이면) 4파렛트 + 363장
- 벽돌 경계값: 면적 0 또는 음수는 에러 메시지
