# 계산 규칙 (lib/quote.ts)

## ㎡당 장수 (벽돌 · 벽돌 타일 공통)
- `올림(1,000,000 / ((길이mm + 12) × (높이mm + 12)))` — 줄눈 12mm, 가운데 값(폭·두께)은 쓰지 않음, 소수점 없음
  - 예: 190x90x57 → 1,000,000 / (202 × 69) = 71.75 → 72장
  - 예: 타일 230x20x76 → 1,000,000 / (242 × 88) = 46.96 → 47장
- `piecesPerSqm`에 직접 값이 있으면 그 값을 우선

## 견적 (장수 계산 전용 — 단가는 자주 바뀌므로 금액은 다루지 않음)
- 면적 단위: ㎡ 또는 평 선택. 평은 **건물 평수** → 외벽 ㎡ = 평수 × 100 / 30 × 층수 (30평 1층 ≈ 외벽 100㎡)
- 로스율 기본값: 타일 10%, 벽돌 5% (화면에서 바꿀 수 있음)
- 필요 장수 = 올림(면적 × ㎡당 장수 × (1 + 로스율))
- 파렛트는 올림하지 않음 → `내림(필요 장수 / piecesPerPack)파렛트 + 나머지 장` (예: 1파렛트 + 968장)
- 장수는 천 단위 쉼표

## 재고 신호등
- 파렛트 수 = stock / piecesPerPack
- 빨강: 5파렛트 미만
- 노랑: 10파렛트 미만
- 초록: 그 외 (10파렛트 이상)

## 재고 검색
- 검색 기준: 제품명(띄어쓰기 · 대소문자 무시, 포함) 또는 사이즈(숫자 1개 = 어느 치수든, 2개 = 길이×높이, 3개 = 전체 규격)
- 필요 수량(선택): 장 또는 ㎡. ㎡는 견적과 같은 계산(기본 로스율 포함)으로 필요 장수를 구해 재고와 비교 → 가능 / 부족 N장

## 샘플
- 단계 순서: 발송 준비 → 발송 → 도착 → 확인완료 (확인완료에서 더 안 감)
- 적는 글: 발송 준비 = 메모, 확인완료 = 피드백, 발송 · 도착 = 없음 (localStorage)
- 발송 준비 → 발송으로 넘기면 sentDate = 오늘
- 발송 단계에서 sentDate로부터 7일 초과면 노란 테두리

## 테스트 (손으로 검산 가능하게 3개 이상)
- 벽돌 190x90x57, 30㎡, 로스 5%: ㎡당 72장 → 필요 2,268장 → (파렛트 1,300장) 1파렛트 + 968장
- 벽돌 ㎡당 75장(직접 값), 30㎡, 로스 5%: 필요 2,363장 → (파렛트 500장이면) 4파렛트 + 363장
- 경계값: 면적 0 또는 음수는 에러 메시지
